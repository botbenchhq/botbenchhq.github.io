First run

Build from source, on a Mac.

About ten minutes. It ends with a branch made by Claude Code in a practice repository, and costs one short Claude Code reply on your subscription. There is no installer and no hosted service.

You need

Before you start

  • macOS. Agents are started only on macOS, because the confinement relies on its sandbox.
  • Node 24 or later.
  • git, set up so you can commit.
  • Claude Code 2.1.322 or later, installed and signed in. Check with claude --version and claude auth status.
  • Codex 0.171.0 or later, only if you want it to review or build.

Do not use it if

Limits worth knowing first

  • You are on Windows or Linux.
  • You want a hosted service or a shared team server.
  • You need a hard security boundary for code you do not trust.
  • You need it stable. It changes often, and nothing is promised to stay the same.

The first branch

Clone, build, start, hand over one task.

  1. Get it and build the screens

    Terminal
    git clone https://github.com/botbenchhq/botbench.git
cd botbench
npm ci
npm ci --prefix web
npm run build --prefix web

  2. Start it

    Leave this terminal open; Ctrl+C stops Botbench. It prints its address, http://127.0.0.1:4780, and on the first start a login token.

    Terminal
    npm start

  3. Sign in

    Open http://127.0.0.1:4780 in a browser on the Mac, paste the token and choose Sign in. You arrive on Chat. Later, read the token with cat ~/.botbench/login-token.

  4. Make a practice repository

    In a second terminal. Copy the path the last line prints.

    Terminal
    mkdir ~/botbench-try && cd ~/botbench-try
git init
echo "# Try" > README.md
git add README.md && git commit -m "Start"
pwd

  5. Start a task

    On Chat, press + under the message box, choose Repository, then Another folder…, and paste the path. When it reads "Usable git repository.", close the sheet. Write the task and choose Send:

    Message
    Add a file hello.txt that says hello, then run ls to show that it is there.

  6. Review and accept

    Within a minute the transcript shows Claude Code writing the file and running ls. The task then reads Ready for review, with hello.txt under Changed files and its branch, such as botbench/your-mac/run-1/task-1. Choose Accept. Botbench keeps the branch and removes the task's copy. Your own branch is unchanged.

These steps follow the README's quickstart, which is the authority and has every detail, including how to clean up and how to use Botbench from your phone over a private network.
